Job Title: Machine Learning Engineer

Company: AI Innovations Lab

Location: Bangalore, India (Hybrid)

Experience: 2-5 Years

Job Description:

We are looking for a Machine Learning Engineer to design, build, and deploy ML models at scale. You will work on cutting-edge AI projects including NLP, computer vision, and recommendation systems.

Responsibilities:
- Design and implement machine learning pipelines for production deployment
- Build and optimize deep learning models using PyTorch and TensorFlow
- Develop NLP solutions including text classification, NER, and sentiment analysis
- Implement computer vision models for image recognition and object detection
- Deploy ML models using Docker, Kubernetes, and cloud-based ML platforms
- Build feature engineering pipelines using Apache Spark and Airflow
- Monitor model performance and implement retraining strategies
- Collaborate with data engineers and software developers on ML integration

Requirements:
- Bachelor's or Master's degree in Computer Science, AI, or related field
- 2+ years of experience in machine learning engineering
- Strong proficiency in Python, PyTorch, and TensorFlow
- Experience with NLP libraries (Hugging Face Transformers, spaCy)
- Knowledge of MLOps tools (MLflow, Kubeflow, Weights & Biases)
- Experience with cloud ML services (AWS SageMaker, GCP Vertex AI)
- Understanding of distributed computing and model optimization
- Strong software engineering skills and experience with Git

Nice to Have:
- Experience with large language models (LLMs) and prompt engineering
- Knowledge of reinforcement learning
- Experience with edge deployment and model compression
- Published research or open-source contributions in ML
